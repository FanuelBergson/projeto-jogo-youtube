# Análise Crítica e Reflexão do Aprendizado (Git e GitHub)

## Introdução
O desenvolvimento deste projeto integrador permitiu aplicar de forma prática os conceitos fundamentais de controle de versão estudados no curso de extensão do CEFET-MG. O uso do Git em conjunto com o GitHub transformou a maneira como estruturo o código e gerencio as evoluções de um software/jogo.

## Aprendizados e Desafios
1. **Controle de Histórico com Conventional Commits:** 
   Adotar mensagens padronizadas (`feat`, `fix`, `chore`, `docs`) trouxe clareza absoluta ao histórico do repositório. Qualquer colaborador ou avaliador consegue inspecionar o propósito exato de cada alteração sem esforço.
2. **Trabalho com Branches e Pull Requests:** 
   A separação do desenvolvimento em ramificações específicas (`feature/parallax-fundo`, `feature/player-camera`) evitou alterações diretas na branch principal (`main`), garantindo estabilidade e permitindo a integração segura via Pull Requests.
3. **Gestão de Tarefas com Issues:** 
   O uso de Issues associadas aos commits (`closes #N`) demonstrou a importância da rastreabilidade: cada modificação no código tem um objetivo de negócio ou requisito técnico claramente mapeado.

## Conclusão
O fluxo baseado em Git consolidou boas práticas essenciais para a engenharia de computação, garantindo escalabilidade, organização profissional e segurança no versionamento de projetos de desenvolvimento de jogos.
